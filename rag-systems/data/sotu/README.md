# State of the Union addresses used by module 12

Nine addresses (1950 to 2006) from the `state_union` corpus distributed with NLTK. They are works of the
United States federal government (public domain). Original source: The American Presidency Project,
https://www.presidency.ucsb.edu/. The files are copied here unchanged, apart from dropping bytes that are not
valid UTF-8, so the notebook runs offline with nothing to download.
