Welcome back.

Build it, then use the library

Every core idea is first written by hand in NumPy or a few lines of PyTorch, checked numerically, and only then replaced by the framework version.

Small enough for a laptop

Models are sized to train on a CPU in seconds to minutes while still showing the real behaviour: learned filters, attention that reorders words, skills that emerge during training.

Honest results

Every model is compared with a baseline, every metric is measured on held-out data, and the notebooks say plainly when a technique does not help.

Syllabus

Three parts, nine modules. Each module is one notebook: read the explanations, run the cells, then try the exercises at the end. Your progress is remembered in this browser.

Run it yourself

Each lesson page shows the notebook with its saved outputs, so you can read the whole course in the browser. To experiment, download a notebook or open it in Google Colab from the lesson page, or clone the repository and run everything locally:

git clone ${repo}.git
cd academy/${repo_path}
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
jupyter lab

What you need

  • Python: comfortable with functions, loops and lists. NumPy experience helps but is introduced as we go.
  • Maths: high-school algebra; derivatives are explained when they appear. No linear algebra course required.
  • Hardware: any laptop from the last decade. The longest notebook (the GPT) trains in about 15 minutes on a CPU.
